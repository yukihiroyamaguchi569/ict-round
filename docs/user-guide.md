# ICTラウンドアプリ「めぐる君」 取扱説明書

**文書番号:** ICT-UG-001  
**対象者:** ICTメンバー・感染対策ラウンド実施者  
**作成日:** 2026年4月18日  
**最終更新日:** 2026年10月10日  
**対象バージョン:** 1.20.0

---

## 1. アプリ概要

### 1.1 目的
本アプリは、病院内の感染対策ラウンドを効率的に実施・記録するためのツールです。チェックリスト評価、写真記録、総評入力、Word 報告書出力を 1 つの画面遷移で行えます。

### 1.2 アプリ名称
**ICTラウンドアプリ「めぐる君」**  
開始画面や外観設定では、キャラクターアイコンとして「らんちゃん」「めぐる君」を切り替えできます。

### 1.3 動作環境

| 項目 | 要件 |
|------|------|
| 対応端末 | スマートフォン、タブレット、PC |
| 対応OS | iOS、Android、Windows、macOS |
| 対応ブラウザ | Safari、Chrome、Edge の比較的新しい版 |
| ネットワーク | 初回アクセス時と更新取得時に必要 |

> Service Worker によりアプリ本体はキャッシュされます。初回読み込み後は、同じ端末・同じブラウザで再訪した際にオフラインでも起動できる場合があります。

## 2. ホーム画面への追加

アプリは PWA として配布されており、ホーム画面やアプリ一覧に追加して起動できます。

未追加の状態でアプリを開くと、画面に**インストールの案内バナー**が表示されます。バナーのボタンから追加できます。バナーを閉じた場合は再表示されないため、その場合は以下の手順で追加してください。

### iPhone / iPad の場合（Safari）
1. Safari でアプリの URL を開く
2. 共有ボタンをタップ
3. 「ホーム画面に追加」を選択
4. 「追加」をタップ

### Android の場合（Chrome）
1. Chrome でアプリの URL を開く
2. メニューを開く
3. 「ホーム画面に追加」または「アプリをインストール」を選択
4. 画面の案内に従って追加

## 3. 操作手順

### 3.1 ラウンド開始

1. アプリを起動すると開始画面が表示されます
2. 使用するチェックリストを選択します
3. **担当者名**を入力します（必須）
4. 必要に応じて **病棟名** を入力します（任意）
5. 「ラウンド開始」をタップします
6. 実施日時が自動入力され、メイン画面が開きます

**新機能のお知らせ:** アプリが更新された後に初めて開始画面を開くと、追加・変更された機能を紹介するお知らせが表示されます。初めてアプリを使う端末でも、最新の更新内容が 1 回だけ表示されます。「閉じる」をタップすると、同じ内容は再び表示されません。過去の更新内容は「更新履歴をすべて見る」または `/updates` ページから確認できます。

**サンプルデータで試す:** 入力済みのサンプルで、報告書の出力までを試せます。初めて使うときに、どのような報告書ができるかを確かめるのに使ってください。

1. 開始画面の `サンプルデータで試す` をタップします（担当者名の入力は不要です）
2. 標準チェックリストの全項目に評価が入り、写真 3 枚と総評も入ったラウンドが開きます。担当者は「サンプル 太郎」、病棟は「【サンプル】3階東病棟」です
3. 画面下部の `レポート` から、通常のラウンドと同じ手順で報告書を出力できます（3.7 を参照）

- サンプルのラウンドは保存されません。画面上部に「サンプルです（保存されません）」と表示され、`保存` ボタンはありません。トップ画面に戻るときも保存の確認は出ません
- 報告書の表題には【サンプル】が付きます
- 開始画面で選んでいるチェックリストにかかわらず、標準チェックリストを使います
- サンプルの写真はアプリに同梱されたイラストです。読み込めなかった写真は入らずにサンプルが開きます
- 評価や総評を変えて試すこともできます。変えた内容は、トップ画面に戻ると消えます
- その端末でまだラウンドを保存したことも報告書を出力したこともないうちは、`ラウンド開始` の下に大きく表示されます。通常のラウンドを保存するか報告書を出力すると（サンプルの報告書の出力は数えません）、画面下部のリンクに移ります。保存済みラウンドがあるときも、画面下部のリンクに表示されます

**画面下部のリンク:** 開始画面のいちばん下（`複数部署のレポートを統合` の下）に、次の 4 つがあります。画面の幅に収まらないときは 2 行に折り返して表示します。`サンプルデータで試す` が `ラウンド開始` の下に表示されていないときは、その前に `サンプルデータで試す` も並びます。

- `使い方`: この使い方ガイドを別のタブで開きます
- `めぐる君について`: アプリの紹介ページを別のタブで開きます
- `同僚に紹介する`: アプリを人に紹介するための送り先を選ぶ画面を開きます（3.9 を参照）
- `ご意見・ご要望`: 質問や改善のご要望を送るお問い合わせフォームを別のタブで開きます（3.10 を参照）

### 3.2 チェックリストの選択・作成・取り込み

開始画面では、使用するチェックリストを切り替えられます。

- 初回起動時は **標準チェックリスト** が自動で登録されています
- 標準チェックリストは **9カテゴリ・22項目** です
- `新しいチェックリストを追加する` から、独自のチェックリストを画面上で作成するか、ファイルから取り込めます
- 各チェックリストの `複製して編集` ボタン（コピーのアイコン）から、既存のチェックリスト（標準チェックリストを含む）を元に新しいチェックリストを作れます

作成・複製・取り込みのいずれも、**新しいチェックリストとして追加**されます。元のチェックリストは変更されないため、保存済みラウンドにも影響しません。保存すると、追加したチェックリストが選択された状態になります。

**画面で作成する手順**

1. 開始画面の `新しいチェックリストを追加する` → `画面で作成する` をタップ
2. チェックリストの名前を入力
3. カテゴリ名と点検項目を入力
   - `項目を追加` でカテゴリ内の点検項目を、`カテゴリを追加` でカテゴリを増やせます
   - ↑↓ ボタンで項目やカテゴリの順番を入れ替えられます
   - × ボタンで項目やカテゴリを削除できます（項目が入力されたカテゴリを削除するときは確認が表示されます）
4. `保存して適用` をタップ

空欄の点検項目と、点検項目のないカテゴリは保存時に省かれます。チェックリストの名前が空の場合、点検項目が1つもない場合、同じ名前のカテゴリが2つある場合は、保存せずにメッセージを表示します。

**紙や Excel の表を貼り付けて作る手順**

病院で使っている紙のチェックリストや Excel・Word の表がある場合は、文字をコピーして作成画面に貼り付けると、カテゴリと点検項目に振り分けて読み込めます。写真から文字を読み取るのは iPhone・Android の機能で、写真がこのアプリに送られることはありません。読み取りの扱いは端末 OS や使うアプリの機能によります。機能によっては写真が提供元のサーバーへ送られることがあるため、患者情報が写り込まないようにしてください。

1. 表の文字をコピーする
   - **iPhone・iPad**: カメラで紙の表を写し、テキスト認識のボタンを押す → すべて選択 → コピー（写真アプリで撮った写真からも同じ操作でコピーできます）
   - **Android**: Google レンズで紙の表を写し、`テキスト` → すべて選択 → コピー
   - **Excel・Word**: 表のカテゴリと点検項目の列を選んでコピー
2. 作成画面（`画面で作成する` または `複製して編集`）で、名前欄の下の `表のテキストを貼り付けて読み込む` をタップ
3. 欄に貼り付ける。下に振り分けの結果（カテゴリ数・項目数と、カテゴリごとの項目）が表示されます
4. 振り分けが違うときは、欄の中の文字を直す。行頭に `■` を付けた行はカテゴリになります。`■` を 1 行でも付けると、`■` のない行はすべて点検項目になります。読み取りの誤字もここで直せます
5. `読み込む` をタップ。何も入力していない作成画面では読み込んだ内容に置き換わり、入力済みの項目がある場合はその後ろに加わります
6. 作成画面でカテゴリ名や項目を確認・修正し、`保存して適用` をタップ

振り分けは次のように行います。

- Excel・Word の表: 1 列目をカテゴリ、2 列目を点検項目として読み、3 列目以降（評価など）は使いません。1 列目が「No.」のような通し番号の列だと判断した場合は、その次の列からをカテゴリ・点検項目として読みます。カテゴリの欄が空の行（セルを結合した表）は、上のカテゴリの項目になります
- 写真から読み取った文字: 短く文末に句点のない行をカテゴリ、それ以外を点検項目として読みます。「手指衛生 病室の入退室時に…」のように 1 行にカテゴリと項目が並んだ行は、最初の語をカテゴリにします。見出し（ジャンル・チェック項目・評価など）、評価だけの行（A・B・C・○・× など）、ページ番号は読み飛ばします
- 短い点検項目（「手袋交換」など）はカテゴリと読まれることがあります。点検項目のないカテゴリはプレビューに「項目なし」と表示されるので、カテゴリの行に `■` を付けて直してください
- 同じ名前のカテゴリは 1 つにまとめます。カテゴリより前にある項目は名前が空のカテゴリに入るので、保存の前にカテゴリ名を入力してください

**複製して編集する手順**

1. 開始画面で元にしたいチェックリストの `複製して編集` をタップ
2. 名前（初期値は「〇〇のコピー」）、カテゴリ、点検項目を必要に応じて変更
3. `保存して適用` をタップ

**ファイルから取り込む手順**

1. 開始画面の `新しいチェックリストを追加する` → `ファイルから取り込む` をタップ
2. 必要ならチェックリスト名を入力
3. `.csv` / `.xlsx` ファイルを選択
4. プレビュー内容を確認
5. `保存して適用` をタップ

**取り込みファイルの形式**

- 1列目: カテゴリ名
- 2列目: 点検項目
- 見出し行は省略可。見出し行の上に空行やタイトル行があっても読み込めます
- Excel は先頭シートのみ読み込みます

### 3.3 チェックリスト評価

ラウンド開始後は `チェック` タブが開きます。

**評価方法**

| 評価 | 意味 |
|------|------|
| **A** | 適切・問題なし |
| **B** | 概ね良好・改善余地あり |
| **C** | 要改善 |

- 各項目の A / B / C ボタンをタップして評価します
- 画面上部とカテゴリごとに進捗が表示されます
- 画面上部の `?` ボタンをタップすると、この使い方ガイドが別のタブで開きます。入力中のラウンドはそのまま残ります
- カテゴリは開閉できます

### 3.4 写真の撮影・追加

写真は `写真` タブから追加できます。チェック項目に紐付く写真と、汎用写真の両方に対応しています。

**汎用写真を追加する場合**

1. `写真` タブを開く
2. `写真を追加` をタップ
3. カメラ撮影または写真選択を行う
4. 必要に応じてコメントを入力
5. `追加する` をタップ

**項目に関連する写真として追加する場合**

1. 該当項目から写真追加導線を開く
2. 写真を選択または撮影する
3. 必要に応じてコメントを入力
4. `追加する` をタップ

**写真に関する仕様**

- 取り込み可能なのは 10MB 以下の画像ファイルです
- 画像はブラウザ内で JPEG に圧縮して保存されます
- 追加済み写真は `写真` タブから削除できます

> 端末やブラウザによっては、撮影ボタンからカメラが直接起動しないことがあります。その場合は、端末のカメラアプリで撮影してから、ギャラリーから選択して読み込んでください。記録できる内容は変わりません。

### 3.5 総評の入力

1. `総評` タブを開きます
2. テキストエリアに総評を入力します
3. 必要に応じて `・ 箇条書き` ボタンで箇条書き記号を追加します

> 長文の入力には、端末のキーボードに備わっている音声入力機能もご利用いただけます（5.3 を参照）。

### 3.6 保存済みラウンドの保存・再開

本アプリでは、途中経過を手動保存できます。

**保存する方法**

1. メイン画面上部の `保存` をタップ
2. 保存が成功すると `保存済み` 表示になります

**再開する方法**

1. 開始画面で `保存済みラウンドを開く` をタップ
2. 一覧から対象ラウンドを選んで `開く` をタップ

**削除する方法**

1. 保存済みラウンド一覧を開く
2. 対象ラウンドの `削除` をタップ

**開始画面（トップ画面）に戻る方法**

1. メイン画面左上のアプリアイコンをタップ
2. 保存されていない変更がある場合は確認ダイアログが表示されます
   - `保存して戻る`: 保存してから開始画面に戻ります
   - `保存せずに戻る`: 保存せずに開始画面に戻ります（変更内容は失われます）
   - `キャンセル`: メイン画面に留まります
3. 開始画面に戻ると、直前に入力した担当者名は入力済みのまま残ります。同じ担当者が続けて別の病棟を回るときは、病棟名だけを入れ替えて「ラウンド開始」をタップできます（病棟名は毎回空になります）

### 3.7 レポートプレビュー・出力

1. 画面下部の `レポート` をタップ
2. プレビュー画面で内容を確認します
3. 右上のボタンから出力します

出力方法は端末により異なります。

- **共有**: ファイル共有に対応した端末では、メールや AirDrop などへ `.docx` ファイルをそのまま渡せます
- **Word出力**: `.docx` ファイルを端末に保存します。共有に対応していない端末、および共有に失敗した場合はこちらの表示になります

共有を終えるか `Word出力` で保存すると、ボタンの下に `使ってみた感想を送る` が表示されます。押すとお問い合わせフォームが別のタブで開きます（3.10 を参照）。共有画面を閉じて取りやめた場合は表示されません。

報告書には以下が含まれます。

- 担当者
- 病棟
- 実施日時
- チェックリスト評価
- 写真記録
- 総評

総評を入力していない場合は、総評の見出しと空の行だけが出力されます。Word で開いてから書き加えられます。

ファイル名は `ICTround_<日付>_<英数4文字>.docx` の形式です。日付は報告書を出力した端末の日付です。半角英数のみとし、複数人分を受け取っても重ならないよう末尾に 4 文字を付けています。

> この `.docx` には、複数部署の報告書を統合するためのラウンドデータ（評価・写真・総評）が機械が読める形で埋め込まれています（3.8 を参照）。Word で開いた見た目は通常の報告書と変わりませんが、**ファイルを渡すと記録の内容も一緒に渡る**ことになります。渡す相手にご注意ください。

### 3.8 複数部署のレポートを統合する

部署ごとに分かれてラウンドした場合、各担当者の報告書を 1 本の Word 報告書にまとめられます。統合作業は PC のブラウザで行います。

**準備**

1. 各担当者が 3.7 の手順で報告書（`.docx`）を共有・出力し、まとめ役に送ります
2. まとめ役は受け取った `.docx` を PC に集めます

送るファイルは報告書の `.docx` 1 つだけです。統合に必要なラウンドデータは、この `.docx` の中に収められています。

**統合手順**

1. PC のブラウザでアプリを開き、開始画面の `複数部署のレポートを統合` から `開く` をクリックします（統合ページが別タブで開きます）
2. 集めた `.docx` を枠内にドラッグ＆ドロップするか、`ファイルを選ぶ` から選択します（複数まとめて読み込めます）
3. 読み込んだ報告書の一覧が表示されます。`↑` `↓` で並び順を入れ替えます。この順序がそのまま表の列順になります。病棟名が同じ報告書は 1 つの列にまとまるため、表の列数は読み込んだ件数より少なくなることがあります
4. `×` で不要なファイルを取り除けます
5. 統合結果のプレビューで内容を確認します
6. `Word出力` をクリックして統合報告書を保存します

**統合報告書の内容**

- チェック項目を行、部署（病棟）を列とした表に、全部署の評価が並びます
- **病棟名が同じ報告書は 1 つの列にまとまります。** 1 つの病棟をチェック項目で分担して複数名で回った場合も、担当者ごとに列は分かれません。列見出しは病棟名だけになります
- 同じ病棟で、ある担当者が評価していない項目は、別の担当者が付けた評価で埋まります
- 同じ病棟の同じ項目に違う評価が付いていた場合は、厳しい方の評価（`C` → `B` → `A` の順）を採用します。この場合は画面に警告が出て、どの項目で誰がどの評価を付けたかが表示されるので、内容を確認してください
- 病棟名を入力していない報告書はまとめず、担当者名を列見出しにして 1 件ずつ別の列になります
- セルが `—` になるのは、その病棟のどの報告書にも該当の項目が無い場合と、項目はあるが誰も評価を付けていない場合です。同じ病棟を分担して回った場合、誰か 1 人が評価していれば埋まります
- 表に続いて、病棟ごとの総評と写真が出力されます。1 つの病棟を複数名で回った場合は、1 つの見出しの下に担当者名を添えて総評が並び、写真もまとめて出力されます
- 総評は入力した担当者の分だけ出力されます。誰も入力していない病棟も見出しと空の行は残るので、Word で開いてから書き加えられます
- 表の幅を確保するため、用紙は横向きです。表は部署の数に応じて列幅を調整し、用紙の幅に収めます

**統合時の注意**

- 統合できるのは、v1.15.0 以降で作った報告書です。それより前の版で作った報告書は読み込めません。複数部署で回る前に、参加者全員がアプリを開いて更新しておいてください。v1.15.0 の「新機能のお知らせ」が表示されれば更新済みです
- 統合できる報告書かどうかは、ファイル名で見分けられます。`ICTround_2026-09-24_k3f9.docx` のように、日付の後ろに英数字 4 文字が付いていれば統合できます。`ICTround_2026-09-24.docx` のように日付で終わっているものは、v1.15.0 より前に作った報告書です（受け取った後にファイル名を変えた場合は見分けられません）
- 報告書を出す前に、ラウンドを `保存` しておいてください。報告書を出し直すことになっても、保存済みラウンドを開けば入力し直さずに済みます
- 読み込めなかった報告書は「読み込めなかったファイル」に表示され、残りの報告書だけで統合できます。その場合、読み込めなかった担当者の部署は統合報告書に含まれません
- `Word出力` で統合報告書を作れなかった場合は、その理由が `Word出力` ボタンの下に表示されます。もう一度 `Word出力` をクリックして出力できれば、表示は消えます
- 統合ページは読み込んだデータを保存しません。ページを再読み込みすると読み込み内容は消えます
- Word で開いて保存し直した `.docx` では、統合に必要なデータが失われることがあります。担当者から共有された元のファイルをそのまま読み込んでください
- 部署ごとにチェックリストの内容が違う場合は、全部署の項目を合わせた表になり、その旨が画面に表示されます
- 別々に作ったチェックリストが混ざっていると、項目の文言ごとに行が分かれることがあります（評価が別の項目の行に混ざらないようにするためです）。この場合は画面に警告が出るので、表の内容を確認してください。行を 1 つにまとめたい場合は、同じチェックリストで記録した報告書だけを読み込んでください
- 1 つの報告書の中で、複数のチェック項目が内部的に同じ項目として記録されている場合（チェックリストの作り方によって、まれに起こります。項目の文言やカテゴリが同じとは限りません）、その報告書の評価が一部表に載らないことや、項目に付けた写真が重複したり別の項目名の下に出ることがあります。この場合は画面に警告が出て、どの報告書のどの項目かが示されるので、表と写真の内容を確認してください
- 読み込めるファイルは 1 つあたり 50MB までです。超える場合はその旨が表示されます
- 表の列（病棟）の数が 15 件を超えると、部署の列が狭くなって読みにくくなります。この場合は画面に警告が出ます

## 5. 注意事項

### 5.1 データ保存について

- 画面上で入力中の内容は自動保存されません
- 途中経過を残すには、必ず `保存` ボタンを押してください
- 保存済みラウンド、チェックリスト、テーマ、アイコンは端末ブラウザの `localStorage` に保存されます
- ブラウザのデータ削除やサイトデータ消去を行うと保存内容は削除されます
- 保存内容は暗号化されません。端末の画面ロックとストレージ暗号化で保護する設計のため、必ず画面ロックを設定してご利用ください
- 入力した内容がサーバーへ送信されることはありません
- 担当者が共有・出力した報告書（`.docx`）には、統合機能のためにラウンドの記録が埋め込まれています（3.7、3.8 を参照）。統合ページが出力する統合報告書には埋め込まれません。端末外へ持ち出したファイルの取り扱いにはご注意ください
- レポート出力後は、保存済みラウンドを削除しておくことを推奨します。共用端末では、使用後にブラウザのサイトデータを削除してください

### 5.2 写真について

- 写真に患者の個人情報が写り込まないよう注意してください
- 写真は外部サーバーへ送信されません
- 保存済みラウンドに含めた写真は端末ブラウザ内に保持されます

### 5.3 音声入力について

- **本アプリに音声入力機能はありません**（v1.7.6 で廃止しました）。アプリがマイクを使うことはありません
- 端末のキーボードに備わっている音声入力機能で文字を入力することは可能です
- その場合、音声の扱いは端末 OS の機能によります。OS によっては音声が提供元のサーバーへ送信されるため、患者情報は発話しないでください
- 利用可否は施設のポリシーに従ってご判断ください

### 5.4 アクセス解析について

- 利用状況の把握のため、Google Analytics 4 によるアクセス解析を行っています
- 解析で送信されるのは、ページの閲覧やインストール操作といった利用状況の情報です
- **担当者名、病棟名、チェック結果、写真、総評が送信されることはありません**
- 詳細は[プライバシーポリシー](https://ict-round.conect.llc/docs/privacy-policy)をご覧ください

## 6. よくある質問（FAQ）

**Q. 入力途中で閉じても続きから使えますか？**  
A. 自動保存はされません。続きから使うには、事前に `保存` ボタンで保存済みラウンドとして残してください。

**Q. 保存済みラウンドはどこに保存されますか？**  
A. この端末・このブラウザの `localStorage` に保存されます。他端末とは共有されません。

**Q. チェックリストを病棟ごとに分けられますか？**  
A. できます。開始画面でチェックリストを画面上で作成する（既存のチェックリストを複製して編集することもできます）か、CSV または Excel を取り込み、使うチェックリストを選択してください。紙のチェックリストは、iPhone のテキスト認識や Google レンズでコピーした文字を作成画面に貼り付けて取り込めます（3.2）。

**Q. 写真が追加できません。**  
A. ブラウザのカメラまたは写真ライブラリへのアクセス許可、またはファイルサイズ上限 10MB を確認してください。

**Q. 撮影ボタンを押してもカメラが起動しません。**  
A. 端末やブラウザによって起動しないことがあります。端末のカメラアプリで撮影してから、ギャラリーから選択して読み込んでください。

**Q. 複数名で分担してラウンドしたいのですが。**  
A. 担当ごとに別々のラウンドとして記録し、それぞれ報告書（`.docx`）を出力してまとめ役に送ってください。集めた報告書は、PC で統合ページを開いて読み込むと 1 本の Word 報告書にまとめられます（3.8 を参照）。1 つの病棟をチェック項目で分担した場合は、病棟名を同じにしておくと 1 つの列にまとまります。なお、1 回のラウンドを複数台の端末で同時に記録することはできません。

**Q. 統合ページで「ラウンドデータが入っていません」と表示されます。**  
A. 次の 2 つが考えられます。

- v1.15.0 より前の版で作った報告書: 担当者がアプリを開いて更新し、保存済みラウンドを開いて報告書を出し直してください。ラウンドを保存していなかった場合は、入力し直す必要があります
- Word で開いて保存し直した `.docx`: 統合に必要なデータが失われることがあります。担当者から共有された元のファイルをそのまま読み込んでください

**Q. 音声入力のボタンがなくなりました。**  
A. v1.7.6 でアプリの音声入力機能を廃止しました。端末のキーボードに備わっている音声入力機能をご利用ください（5.3 を参照）。

**Q. 使い始める前に、どのような報告書ができるか見られますか？**  
A. 開始画面の `サンプルデータで試す` から、入力済みのサンプルで報告書の出力まで試せます。サンプルは保存されず、保存済みラウンドにも残りません（3.1 を参照）。

**Q. 出力形式は PDF ですか？**  
A. いいえ。出力形式は `.docx` です。

**Q. 入力したデータがサーバーへ送られることはありませんか？**  
A. ありません。担当者名、病棟名、チェック結果、写真、総評は端末内にのみ保存されます。アクセス解析でも送信されません（5.4 を参照）。

**Q. 院内の情報セキュリティ審査に出せる資料はありますか？**  
A. [技術仕様書](https://ict-round.conect.llc/docs/technical-spec)と[プライバシーポリシー](https://ict-round.conect.llc/docs/privacy-policy)をご利用ください。データの保存先、外部通信先、アクセス解析で送信する項目を記載しています。
